# inference-workloads

Production-grade synthetic datasets for long-context, multi-turn, agentic inference benchmarking.

Built to stress-test KV cache reuse, offloading, long-context growth, prefix sharing, and disaggregated serving — the workload patterns that actually matter for production inference deployments.

## What this is

**24 canonical traces** totaling ~1.2M tokens across 2 workload families:

| Family | Traces | Context bins | What it stresses |
|--------|--------|-------------|-----------------|
| `long_chat` | 12 | 8K–128K | TTFT growth, prefix reuse, resumed sessions |
| `coding` | 12 | 16K–128K+ | Large prefixes, tool use, branch/retry, offload |

**4 replay manifests** for different benchmark modes:

| Manifest | What it tests |
|----------|--------------|
| `interactive_steady_state_v0` | Natural session interleaving |
| `shared_prefix_swarm_v0` | Prefix caching vs offload |
| `reactivation_stress_v0` | Idle → reload cost |
| `offload_cliff_v0` | Working set beyond HBM |

## Why not ShareGPT / random sequences

ShareGPT is a 2023 training scrape — no tools, no agents, no timing, no KV-aware fields. Random sequences (InferenceX default) have no realistic prefix sharing or context growth. This dataset has:

- Tool calls, execution loops, branch/retry
- Idle windows and reactivation patterns
- KV pressure metadata (offload bytes, cache expectations, eviction risk)
- Replay semantics (arrival timing, prefix groups, session affinity)

## Generation pipeline

**Planner → Generator → Evaluator** with dual-model generation:

- 12 traces generated by **Claude Code** (Opus)
- 12 traces generated by **Codex**
- Cross-model evaluation: Claude evaluates Codex's traces, Codex evaluates Claude's

```bash
# Install
pip install pydantic

# Generate all 24 traces (resumable — safe to stop/restart)
python -m workloads.synthetic_pipeline generate

# Validate traces
python -m workloads.synthetic_pipeline validate

# Cross-model evaluation
python -m workloads.synthetic_pipeline evaluate

# Build 4 replay manifests
python -m workloads.synthetic_pipeline materialize

# Or run the full pipeline
python -m workloads.synthetic_pipeline all
```

## Schema

Canonical trace schema: `SessionTraceV0` — the single source of truth. Flat rows, replay events, and InferenceX adapters are derived exports.

Key fields beyond standard conversation structure:
- `replay` — prefix groups, overlap ratios, idle windows, arrival patterns
- `kv_pressure` — cache expectations, offload/reload bytes, eviction risk, tier
- `content_blocks` — text, code, log, document, image, table (multimodal-ready)
- `provenance` — which model generated it, prompt version, pipeline version

## Compatibility

Designed as a complement to [InferenceX](https://github.com/SemiAnalysisAI/InferenceX) (addresses [#359](https://github.com/SemiAnalysisAI/InferenceX/issues/359) — real datasets). Adapter layer for InferenceX trace replay format planned.

```
  traces/                   # Generated canonical traces (JSON)
  manifests/                # Replay manifests (JSON)
```
